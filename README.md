# OPF Advisor — документация

## 1. Описание функционала
Веб-приложение помогает предпринимателю выбрать организационно-правовую форму (ИП, ООО, АО) на основе ответов на пять вопросов. Результат содержит рекомендацию и краткое обоснование.

## 2. Инструкция по использованию
1. Запустите приложение: `uv run flask --app src run --debug`.
2. Откройте http://127.0.0.1:5000.
3. Заполните форму: вид деятельности, масштаб, количество учредителей, потребность в инвестициях, готовность к личной ответственности.
4. Нажмите «Получить рекомендацию».
5. Ознакомьтесь с результатом. Для нового расчёта вернитесь на главную.

## 3. Обоснование критериев
Критерии выбраны на основе анализа законодательства РФ и практических руководств по выбору ОПФ:
- **Количество учредителей**: ИП — только 1, ООО — до 50, АО — без ограничений[reference:6].
- **Потребность в инвестициях**: АО и ООО позволяют привлекать инвесторов через доли/акции, ИП — ограничен[reference:7].
- **Ответственность**: ИП рискует личным имуществом, участники ООО/АО — только в пределах вклада[reference:8].
- **Масштаб бизнеса**: малый бизнес чаще выбирает ИП/ООО, крупный — АО[reference:9].
- **Вид деятельности**: влияет на лицензионные ограничения (например, ИП не может заниматься страхованием)[reference:10].

## 4. Технические детали
- Python 3.11+, Flask 3.x, менеджер пакетов `uv`.
- Blueprint-архитектура: `main` (веб-интерфейс) и `api` (JSON).
- Шаблоны Jinja2 с наследованием от `base.html`.
